# healthcare-pharmacy-sales-analysis-task
Pharmacy Sales & Drug Analysis

Project Overview

This project analyzes pharmacy sales data to identify medicine usage trends, revenue patterns, monthly sales growth, and top-selling medicines. It also compares branded and generic medicines using Python, Pandas, and Matplotlib.

Objectives

- Analyze pharmacy sales data.
- Identify top-selling medicines based on revenue.
- Evaluate monthly sales trends and growth.
- Compare sales across medicine categories.
- Analyze branded versus generic medicine sales.
- Generate charts and summary reports to support data-driven decisions.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- CSV datasets
- GitHub

Dataset Description

The dataset contains sample pharmacy sales information, including:

- Date of sale
- Medicine name
- Medicine category
- Quantity sold
- Unit price
- Total sales revenue
- Medicine type (branded or generic)

Note: The project uses synthetic sample data for educational purposes. It does not contain real pharmacy or patient records.

Analysis Performed

1. Monthly Sales Trend: Examines revenue patterns over time.
2. Top-Selling Medicines: Identifies medicines generating the highest revenue.
3. Category-Wise Sales: Compares sales among medicine categories.
4. Branded vs. Generic Analysis: Compares revenue and sales performance by medicine type.
5. Summary Report: Exports key sales statistics to a CSV file.

Installation

Install Python 3.10 or later, then install the required libraries:

pip install -r requirements.txt

How to Run

Run the analysis script from the project directory:

python src/analyze_pharmacy_sales.py

The script generates charts and summary reports in the "outputs/" folder.

Expected Outcomes

- Better understanding of pharmacy sales trends.
- Identification of high-revenue medicines.
- Insights into monthly revenue patterns.
- Comparison of branded and generic medicine sales.
- Visual reports that help summarize sales performance.

Conclusion

This project demonstrates how Python-based data analysis and visualization can be used to understand pharmacy sales, compare medicine performance, and identify useful business insights.
